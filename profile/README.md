# spill

A modern torrent client implemented in Rust.

Download and seed from the command line, run a headless daemon on Linux or macOS, or embed the engine in your own application.

- [Website](https://spill.rs)
- [Source](https://github.com/spillrs/spill)
- [User guides](https://spill.rs/docs/)
- [Rust API reference](https://docs.rs/spill)
- [crates.io](https://crates.io/crates/spill)

## Install

```sh
cargo install spill --locked
```

For the Rust library:

```sh
cargo add spill
```
